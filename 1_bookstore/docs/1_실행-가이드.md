# 실습 1 — 온라인 서점 protobuf 모델링

`book.proto`로 책/고객/주문 메시지를 정의하고, Python에서 직렬화/역직렬화 해보는 실습.

> **개념을 먼저 이해하고 싶다면** → [`2_구조와-흐름.md`](2_구조와-흐름.md) 부터 읽으세요.
> **바로 손으로 해보고 싶다면** → 아래 "실행 순서"를 따라가세요.

## 파일 구성

```
1_bookstore/
├── book.proto              ← protobuf 메시지 정의 (입력)
├── serialize_example.py    ← 직렬화/역직렬화 예시 코드
└── docs/
    ├── 1_실행-가이드.md    ← 이 파일 (실행 방법)
    └── 2_구조와-흐름.md    ← 개념·다이어그램 설명
```

컴파일 후 추가 생성 (`1_bookstore/` 직하):
```
├── book_pb2.py             ← 메시지 클래스 (자동 생성)
└── book_pb2_grpc.py        ← gRPC stub (자동 생성, 이번엔 비어있음)
```

## 실행 순서

### 1단계 — 폴더 이동

```bash
cd 1_bookstore
```

> 컴파일과 실행은 항상 `1_bookstore/` 안에서 합니다 (`docs/`가 아닙니다).

### 2단계 — proto 컴파일

```bash
uv run python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. book.proto
```

성공 시 두 파일이 생성됩니다:
- `book_pb2.py` — 메시지 클래스 (`Book`, `Customer`, `Order`)
- `book_pb2_grpc.py` — gRPC stub (이번 실습에서는 비어 있음, `service` 정의가 없기 때문)

> 두 파일이 왜 분리되어 생성되는지는 [`2_구조와-흐름.md` §2](2_구조와-흐름.md) 참고.

### 3단계 — 예시 실행

```bash
uv run python serialize_example.py
```

예상 출력:
- 원본 `Book` 객체 내용
- 직렬화된 바이너리 `bytes`
- 역직렬화 결과
- `Order`에 `Customer`와 `repeated Book`이 들어간 모습

## 확인할 학습 포인트

1. **proto3 문법**: `타입 필드명 = 번호;`
2. **메시지 참조**: `Customer customer = 2;` — 다른 메시지를 필드로 사용
3. **repeated**: `repeated Book items = 3;` — 리스트/배열 표현
4. **직렬화**: `obj.SerializeToString()` → `bytes`
5. **역직렬화**: `new_obj.ParseFromString(bytes_data)`
6. **크기 비교**: JSON으로 같은 데이터를 표현했을 때와 비교해보기

## 직접 확장해보기

- `Author`, `Publisher`를 별도 메시지로 만들고 `Book`이 참조하도록 변경
- `genre`를 `enum`으로 변환
- `Order.shipping_status`도 `enum`으로 (`PREPARING`, `SHIPPED`, `DELIVERED`)
- `Order`에 총액 계산 필드 추가
